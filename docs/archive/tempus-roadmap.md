# Roadmap

Tempus is a date calculator that shows its work. New feature families are paused while we improve the existing experience and test whether people find it useful.

Next work:

1. Fix wrong interpretations and misleading questions before adding accepted wording.
2. Keep the answer, each calculation step and the next correction clear.
3. Check fresh arithmetic inputs with separate agents, then run the independent-user evaluation.
4. Improve resource use only when measurements justify the change. Keep current timezone behavior until its replacement is verified.

Existing schedules remain supported. Reminder delivery and calendar accounts belong to applications using the engine.
