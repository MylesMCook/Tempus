# Tempus Total

A powerful natural language date parser for React applications. Transform expressions like "3 weeks from now" or "next friday" into JavaScript Date objects.

## Features

- 🎯 Natural language date parsing
- 🎨 Ready-to-use React components
- 💪 TypeScript support
- 🔄 Date math support
- 📅 Relative dates support
- 🌍 Localization support

## Installation

\`\`\`bash
npm install tempus-total
# or
yarn add tempus-total
# or
pnpm add tempus-total
